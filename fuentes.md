# 1) Organización Oficial de Jacdac en GitHub:

https://github.com/jacdac

Aloja el catálogo central de dispositivos, especificaciones del protocolo, herramientas web y paquetes TypeScript (`jacdac-ts`).

# 2) Sitio Oficial de Documentación de Jacdac:

https://jacdac.github.io/jacdac-docs/
Manual de arquitectura, especificación de servicios hardware y guía para desarrolladores de clientes y módulos Jacdac.

# 3) Repositorio de la Extensión Jacdac para MakeCode:
https://github.com/microsoft/pxt-jacdac
Código fuente de los servicios host y cliente de Jacdac para los editores de MakeCode (micro:bit V2 y Arcade).

# 4) Guía para la Creación de Extensiones MakeCode:
https://makecode.com/extensions/github-authoring
Tutorial oficial de Microsoft para vincular tu cuenta de GitHub con MakeCode, crear tu repositorio y publicar tu propia extensión de bloques o TypeScript directamente desde el navegador.
